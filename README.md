# Investigation Report Builder

A fast, local-first web app for building structured investigation reports. Fill in case details, device info, findings, and conclusions — and get a clean, formatted report in real time.

## Features

- 📋 **Structured form inputs** — Case details, device info, screenshots, findings, and conclusion sections
- 👁️ **Live preview** — See the formatted report update as you type
- 🌙 **Dark mode** — Toggle between light and dark themes
- 📸 **Screenshot support** — Paste or upload images directly into the report
- 📋 **One-click copy** — Copy the finished report to your clipboard instantly

## Running Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.
